FROGZZSHOP
===========

1. Buka index.html di browser.
2. Semua tampilan website ada dalam satu file.
3. Font Awesome menggunakan CDN.
4. Produk:
   Cari bagian "FROGZZSHOP — EDIT PRODUK DI SINI".
   Tambahkan object baru ke array products:
   {
     icon: "fa-code",
     name: "Nama Produk",
     description: "Deskripsi produk",
     price: "Mulai RpXXK",
     href: "https://link-tujuan.com"
   }

5. Kontak:
   Cari bagian "KONTAK — GANTI LINK DI SINI".
   Ubah:
   whatsapp
   discord
   channel

6. Logo:
   Logo saat ini menggunakan icon Font Awesome. Kamu bisa mengganti icon
   fa-bolt pada elemen .logo dengan icon Font Awesome lain.

7. Tidak memakai framework. Cukup upload index.html ke hosting/cPanel.
